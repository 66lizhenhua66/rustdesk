# 被控端与多端控制端交互设计草案

日期：2026-10-02。版本：v3。状态：**整体风格已获认可，A／B／C 设备页方案尚未选定**。推荐方案 A「设备工作台」，保留 B、C 比较连接效率和设备信息组织。

本轮沿用现有视觉风格，新增 ID＋密码无人值守连接、进入远程后直接使用桌面、仅查看／控制切换和文件传输设计。页面使用模拟设备、画面、文件、连接结果及权限数据，不接实际媒体、网络、系统输入或业务 API。界面的成功状态不表示真实远控、公网安全或鸿蒙系统能力已经验证。

设计参考 [产品规格](../../SPEC.md)、[控制端技术栈](../../specs/002-controller-tech-stack.md) 和 [当前进度](../../PROGRESS.md)。本轮只扩展可评审原型，不修改主规格、现有 POC 范围或验收门槛。产品方向仍是鸿蒙原生优先、各平台维护界面、共享会话核心。

## 1. 目标与边界

- Windows 被控端回答「哪些访问方式已开放、谁在连接、已授予什么、怎样立即撤权或结束」。
- 控制端适配手机、平板和 PC，三种设备页结构共用同一套连接、桌面和权限语义；同一时间只允许一个活动会话。
- 设备 ID、独立 IP／端口与中继表达连接路径；无人值守与临时协助表达认证和授权方式，两者分开。
- 连接成功直接进入桌面。参考 ToDesk 的交互方向，使用可收起的浮动工具栏；默认不常驻设备导航、工具侧栏或触控板。
- 当前使用「仅查看」或「控制」，与被控端是否授予操作权限分开。控制端切换模式不能扩大授权。
- 文件上传和下载分别授权、分别撤销；控制权限不隐式开启文件传输，文件权限也不授予键鼠操作。
- 终端、隧道、摄像头、远程打印、隐私模式、管理员提权、剪贴板等不在本轮设计的可执行范围。

无人值守仍遵守主规格 §4.3、REQ-012 和 AC-15：本机单独启用，面向现场登记的可信控制设备，要求有效访问凭据、身份绑定、能力限制、可撤销授权和过期控制。ID＋密码是用户看到的连接入口，不能替代这些条件。未完成独立安全验收前，实际产品与 POC 仍按现有有人值守门槛交付。

文件传输沿用主规格 §4.4 的独立方向、操作和目录范围要求；后续文件子连接及实际执行点同样需要权限检查。此处设计上传、下载及重名处理，使用固定的「远程共享」演示目录；不开放删除、任意磁盘浏览或文件剪贴板，不表示首个公网版本已经开放文件协议。

## 2. 三种控制端设备页

| 方案 | 首页结构 | 优势 | 取舍 | 适合情境 |
| --- | --- | --- | --- | --- |
| **A · 设备工作台（推荐）** | 导航、快速连接卡、设备卡 | 输入 ID 与连接常用设备同样直接；手机到 PC 的层级连续 | 大量设备时需要搜索与筛选 | 每天连接自己的少量设备 |
| B · 快速连接 | 单一连接表单、紧凑最近设备列表 | 连接焦点明确，窄屏路径短 | PC 宽屏设备管理密度较低 | 手上已有 ID 或 IP，快速发起一次连接 |
| C · 会话工作区 | 平板／PC 左设备列表、右详情；手机上方选择、下方详情 | 连接前能同时查看设备与访问资料 | 手机详情较长 | 经常在多台设备间选择，但逐台连接 |

三种方案仅比较设备页组织，不改变功能范围或授权方式。A 的手机设备卡单列、平板双列、PC 三列；B 始终突出连接表单；C 的列表与详情属于连接前工作区，进入远程后使用共用桌面视图。

设备名称、在线状态和最近使用资料是示例，不作为身份凭证。「添加设备」只保存本次页面内存中的名称与设备 ID，不发起连接。保留搜索、全部／在线／常用筛选；不提供设备编辑、删除或收藏管理。

会话中返回设备页不结束连接，通过返回会话入口继续。此时浏览其他设备不会更改活动目标和路径；连接第二台设备时提示先结束当前会话，不静默断开或创建第二会话。

## 3. 自适应与桌面空间

断点按应用可用窗口宽度计算，浏览器原型以 CSS px 演示。系统缩放、分屏、折叠及实际 ArkUI 断点映射仍需平台验证。

| 可用宽度 | 设备页导航 | 远程桌面 | 按需面板与文件传输 |
| --- | --- | --- | --- |
| **手机：小于 600** | 底部导航；设备内容单列 | 桌面使用整个会话区域；顶部紧凑浮动栏可收成状态胶囊 | 工具、键盘、触控板覆盖展示；文件用本机／远端页签 |
| **平板：600–1099** | 导航轨；适合双栏设备内容 | 默认只展示桌面和浮动栏；横竖屏维持当前授权 | 工具按需覆盖；文件弹窗使用本机／远端双栏 |
| **PC：1100 及以上** | 完整侧栏；设备工作台 | 默认无常驻侧栏，桌面获得完整会话区域 | 浮动栏打开工具与文件双栏弹窗，关闭后恢复桌面 |

「桌面铺满」指会话空间交给远程画面，不承诺拉伸或裁切远端显示内容。适应窗口时应保持显示比例；原始比例、滚动与缩放的真实算法属于后续输入和媒体实现。

预览尺寸切换不重新连接、不重置权限、不改变目标设备。小屏面板必须能关闭，主要动作保持可见，面板点击不穿透到远程桌面。599／600、1099／1100 边界和触摸目标尺寸属于验收目标，不能由宽度预设推断已经通过测试。

## 4. 连接入口与访问方式

### 连接路径

| 路径 | 输入 | 原型行为 |
| --- | --- | --- |
| 设备 ID 自动连接 | 9 位设备 ID | 匹配演示设备；路径示例为「协调直连」 |
| IP 直连 | 独立 IP、独立端口字段 | 校验 IPv4／IPv6 格式和 1–65535 端口；使用示例目标 |
| 强制中继 | 9 位设备 ID | 匹配演示设备；路径示例为「加密中继」 |

表单错误就地提示并保留设备资料，不访问填写的地址。真实不可达诊断、身份与地址绑定、加密通道以及自建服务接入属于后续目标；IP 直连不隐式绕过授权策略。

控制端「偏好设置」现在形成默认值闭环：连接策略（直连优先／始终中继）、默认访问方式、默认进入模式、输入方式、画面显示和画质都会回写内存状态；连接卡上的一次性选择只覆盖当前连接，不改默认值。明确填写 IP 时始终使用 IP 直连。当前模拟会话也会显示最新的画面偏好，刷新后恢复示例默认值。

### 无人值守：ID＋密码后直达桌面

评审初始选择无人值守，示例设备 ID 为 `842 916 305`，公开演示密码为 `Desk2026!`。样例预配置为「已启用无人值守、当前控制设备已登记、允许查看与控制、上传和下载关闭」。这是已完成配置后的体验样本，**不是实际产品首次安装默认策略**。

控制端输入设备资料与访问密码，选择以控制或仅查看方式进入。模拟检查设备在线、无人访问已启用、当前控制设备被信任以及密码正确后，直接进入桌面；无需重复走临时协助批准页。密码错误留在认证表单，未启用或未信任时不能进入桌面。

被控端提供无人值守访问配置：访问开关、可信控制设备登记／撤销、修改演示密码和默认能力。每台示例设备拥有独立的无人值守配置；当前会话权限可以在本机单独调整，关闭默认能力会立即撤销对应的当前授权。密码只存在当前页面内存，不写入 URL 或活动记录；刷新恢复样例。真实强随机凭据生成与安全存储、现场绑定、密钥持有证明、防重放、第二因子和失败节流均未实现，演示密码不能用于生产。

原型提供示例控制设备的登记／撤销操作；撤销当前无人会话会立即结束连接，下一次密码连接会被拒绝。真实密钥登记、轮换和撤销服务仍属于后续目标。

每次无人值守连接依据当前预授权重新建立本次会话权限；断开后不能复用旧会话的「已允许」状态。主规格规定的默认 15 分钟无输入断开、最长 8 小时及恢复后重新认证仍然有效，本原型不运行这些计时器或真实认证。

### 临时协助：协助码＋现场批准

临时访问继续使用原路径：本机开启邀请 → 输入临时协助码 → 等待本机批准查看 → 只读桌面 → 按需单独允许操作。

邀请关闭时提示去被控端开启，并保留明确标注的模拟开启入口。协助码固定为示例 `728 461`；10 分钟邀请和 60 秒批准窗口通过模拟事件演示，没有真实倒计时。邀请被请求消耗、关闭或到期后不能再次提交，必须显式重新开启。拒绝、超时或异常不沿用旧批准。

等待批准时不显示桌面。名称、配对码和加密／身份结果均是示例，不能代替生产身份验证；普通请求动作不能直接批准画面或操作。

## 5. 被控端与权限状态

被控端分别展示无人值守访问配置、临时协助邀请和当前会话。没有活动会话与没有开放任何访问方式应使用不同文案：结束一次连接不应把仍启用的无人值守描述为「远程访问已关闭」。

| 场景 | 本机关注内容 | 本机操作 | 控制端结果 |
| --- | --- | --- | --- |
| 无人访问待连接 | 是否启用、已登记控制设备样例、能力上限 | 关闭访问、修改示例凭据和能力；信任管理为后续目标 | 下一次连接按最新策略检查 |
| 临时邀请中 | 本机 ID、单次协助码、有效期说明 | 复制邀请、关闭、模拟到期 | 邀请有效时才可提交请求 |
| 现场批准等待 | 来源、请求查看范围、60 秒说明 | 批准查看、拒绝、模拟超时 | 批准前无桌面，批准后仅查看 |
| 活动会话 | 当前模式与已授予权限 | 授予／撤销键鼠、分别允许／撤销上传下载 | 当前模式与授权同步变化 |
| 连接结束或异常 | 结束原因、当前会话权限已清除 | 发起新临时邀请或按当前无人策略重连 | 旧会话不能继续操作或传输 |

`controlGranted` 表示被控端是否已授予本次键鼠能力，`session` 的 `view`／`control` 表示控制端当前选择的使用模式。两者分别保存，避免把「我先看看」误当成「对方撤销授权」。

| 操作授权 | 当前模式 | 允许行为 | 切换到控制 |
| --- | --- | --- | --- |
| 未授予 | 仅查看 | 查看画面，不能发送模拟键鼠 | 发起请求，等待被控端允许 |
| 已授予 | 仅查看 | 查看画面，暂停模拟键鼠 | 可立即切换，不重复请求 |
| 已授予 | 控制 | 允许模拟键鼠与文字 | 可随时主动切为仅查看 |

被控端撤销键鼠后，立即清除操作授权、切回仅查看并停止输入反馈；控制端不能直接切回控制。文件授权与键鼠授权各自独立，只读会话在已取得文件方向授权时仍可传输。

断开、拒绝、超时、身份异常或网络中断清除本次会话权限与请求，停止未完成传输；重新连接必须重新满足当前访问策略。无人预授权配置与本次会话权限是不同对象，配置仍有效不意味着旧会话继续有效。

## 6. 控制端远程会话

三种设备页方案连接成功后均进入同一桌面。浮动工具栏提供设备与模式摘要、模式切换和按需工具入口，可收起为较小的状态胶囊；断开入口保持可发现。设备导航不常驻会话中，返回设备页通过独立动作完成。

桌面是单显示器示意。默认无侧栏、无常驻触控板；工具、键盘、触控板与文件传输在需要时覆盖打开，关闭后恢复桌面空间。模拟远端授权或异常的入口应标注「原型演示」，不能与普通授予动作混淆。

手机可选择触控板或直接触控；触控板不再长时间占据桌面下半部。点击键盘后聚焦不可见的输入控件，去掉本地文本框与发送按钮；只保留输入状态、收起入口与快捷键。文字直接更新模拟远端记事本，切换被控端可看到相同内容。平板和 PC 采用同样的权限与模式含义，根据空间安排浮动栏和覆盖面板。

隐藏输入控件独立于会话画面，不随画面重绘而销毁。中文组合中不转发拼音草稿，选词确认后按输入变化提交；尾随 input 不重复提交。退格、回车与 Tab 在原型中改变记事本文字，其余功能键仅作命令反馈。失焦、仅查看、撤权、断开或切角色立即停捕获并丢弃未确认组合，不自动恢复旧输入。文字仅保存在会话内存，不进入日志与网址。

适应窗口、画质偏好和示例指标用于比较交互；相对指针移动、双指滚动与缩放、长按拖拽、完整物理键鼠、原生输入法、软键盘弹出与避让、系统级按键释放和系统保留快捷键仍需真实实现与真机验证。软键盘文字输入不自动启用系统剪贴板。

## 7. 文件传输设计

从远程会话的文件入口打开传输工作区。PC／平板并列展示本机和远端，手机通过两个页签切换；传输队列属于同一会话，不因切页签或关闭面板而改变目标设备。

| 能力 | 方向与范围 | 未授权时 | 撤销时 |
| --- | --- | --- | --- |
| 上传 | 本机 → 被控端允许的接收目录 | 提示请求上传权限，不能创建有效上传任务 | 停止该方向未完成任务，禁止继续／重试 |
| 下载 | 被控端允许的共享目录 → 本机 | 隐藏远端文件列表，提示请求下载权限 | 隐藏远端列表，停止该方向未完成任务 |

本轮使用固定的示例目录和文件，不读取本机文件，不枚举远端真实目录，也不执行网络传输。生产目录范围、文件选择器、系统权限、磁盘与路径校验等另行实现。文件请求必须由被控端独立允许，模拟允许入口保持明确标识。

队列展示方向、示例文件名、进度与状态，提供手动推进、暂停、继续、取消和模拟失败。所有进度变化均为演示，不对应真实字节传输。撤权停止对应方向的未完成和失败任务；结束会话停止所有方向的未完成和失败任务，不能靠继续或重试恢复过期授权。

队列、模拟目录、文件选择和当前目录仅属于这一次会话。新会话重置文件工作区，不把前一台设备的任务和模拟文件带到下一台设备，也不演示跨会话或跨设备续传。

重名冲突提供「保留两份」「跳过」「替换」：保留两份生成示例副本名称，跳过结束该任务；替换先展示二次确认，确认前不推进为完成。这里不修改或覆盖真实文件，也不开放文件删除。生产版本的同名比较、续传、部分文件清理、原子替换与磁盘不足处理属于后续专项设计。

## 8. 异常与可见反馈

状态摘要优先回答「连到谁、允许做什么、当前处于哪个模式」。网络质量和模拟绿色状态不能改变授权结论。延迟、帧率、路径和身份结果均应标明示例来源。

| 情况 | 原型可见结果 | 下一步 |
| --- | --- | --- |
| ID／IP／端口不合法 | 表单内提示，保留设备资料 | 修正后提交 |
| 无人访问密码不正确 | 留在认证表单，无桌面 | 修正密码 |
| 无人访问关闭或当前控制设备不可信 | 拒绝无人连接 | 在本机配置访问，或改用临时协助 |
| 示例设备离线 | 不建立会话 | 核实目标状态；真实网络诊断后续实现 |
| 临时协助拒绝／邀请或批准超时 | 流程结束，邀请失效 | 显式开启新邀请 |
| 身份异常 | 结束连接，不提供绕过 | 核实绑定后重新连接 |
| 键鼠被撤销 | 保留只读画面，禁用输入 | 继续查看或重新请求 |
| 某方向文件权限被撤销 | 停止该方向任务；下载撤权后隐藏远端列表 | 再次取得独立授权后才能创建新任务 |
| 文件冲突／失败 | 队列显示原因和可用处理动作 | 选择冲突策略，或在授权有效时重试 |
| 网络中断／会话结束 | 当前权限清空，未完成任务停止 | 按当前访问方式重新认证与授权 |

## 9. 交互验收目标

以下是评审与验证清单，不是全部测试通过的声明，也不代替连接、媒体、安全、文件或真机测试。

1. A／B／C 保留一致视觉语言，设备页组织不同，连接后共用完整桌面和浮动栏。
2. 检查手机竖屏／横屏、平板、PC 和断点边界；主要动作可见，面板可关闭，无意外横向溢出。
