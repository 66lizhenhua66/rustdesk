# Remote Desk 双端交互原型

日期：2026-10-02。版本：v3。状态：整体风格已获认可，A／B／C 设备页方案尚未选定。

本目录独立展示 Windows 被控端与手机、平板、PC 控制端。本轮补充无人值守的 ID＋密码连接、连接后直接进入桌面的会话，以及独立授权的文件传输。纯 HTML / CSS / JavaScript，无依赖、无构建；所有设备、文件、连接与权限事件均为模拟，不接入 POC。

状态仅保存在当前页面内存，刷新后重置；网址只保留角色、方案、预览尺寸与方向。

## 打开

在本目录执行：

```powershell
node server.cjs
```

浏览器打开 <http://127.0.0.1:4318>。端口被占用时可用 `node server.cjs 4319`；服务仅监听本机回环地址。

## 评审入口

- A 设备工作台（推荐）：`/?variant=A&role=controller&viewport=pc`
- B 快速连接：`/?variant=B&role=controller&viewport=phone`
- C 会话工作区：`/?variant=C&role=controller&viewport=tablet`
- Windows 被控端：`/?variant=A&role=host&viewport=pc`

顶部切换控制端／被控端、手机／平板／PC 和横竖屏；底部切换 A／B／C。方案切换保留当前内存会话，通过返回会话入口继续查看。三种方案共用同一会话界面。

## 建议体验顺序

1. 默认展示已完成配置的无人值守样例：设备 ID `842 916 305`，演示密码 `Desk2026!`。选择「控制」或「仅查看」后连接，凭据正确即进入远程桌面，不经过临时协助批准页。
2. 点击「键盘」后直接输入：界面不再显示文本框或发送按钮。输入会即时出现在模拟远端记事本；中文先在本地选词，确认后才提交。可用退格、回车和 Tab；切到被控端能查看相同的已接收文字。收起键盘或离开输入焦点后暂停，点击键盘可继续。
3. 在「控制」与「仅查看」之间切换。已有操作授权时可切回控制；到被控端撤销操作授权后，控制端立即变为仅查看，再次请求操作不能自行授权。
4. 打开文件传输。默认上传、下载都未授权；分别请求并在被控端允许。PC／平板比较本机与远端双栏，手机切换本机／远端页签。下载授权之前不显示远端文件列表。
5. 使用示例文件创建任务，体验手动推进、暂停／继续、取消、失败和重名冲突；重名可保留两份、跳过或在二次确认后替换。撤销某个方向的权限，观察该方向未完成任务停止；断开会话停止全部未完成任务。
6. 切到被控端的无人值守配置，查看访问开关、已登记控制设备样例、修改演示密码与能力上限。每台示例设备有独立的访问配置；关闭无人值守或撤销可信控制设备后，再尝试无人连接会被拒绝。
7. 将访问方式改为临时协助，开启一次邀请，提交演示协助码 `728 461`；被控端批准查看后，才能进入桌面。再体验单独允许操作、撤权、拒绝、邀请到期、批准超时和网络中断。

无人值守样例预设为「已启用、当前控制设备已登记、允许控制、上传与下载关闭」，用于缩短评审路径；**这不是实际产品首次安装的默认策略**。公开示例密码不能作为生产凭据。真实身份登记、强随机凭据、认证、防重放、失败节流、撤销与超时执行均不在本原型内实现。

## 本轮范围与边界

本轮覆盖三种设备页结构、手机／平板／PC 会话布局、ID／独立 IP 与端口／中继入口、无人值守与临时协助分流、仅查看与控制切换，以及文件上传／下载独立授权。控制端偏好设置会影响下一次连接，连接卡上的临时访问方式和进入模式只覆盖当前连接；每台示例设备拥有独立无人值守配置。一个页面中的双端视图共享同一内存会话，活动会话固定目标设备与连接路径。

文件队列仅属于当前会话。断开后未完成和失败任务均停止；新会话重置队列、模拟目录与选择，不把上一台设备的任务带到下一台，也不演示跨会话续传。

桌面、文件列表、传输进度、身份结果和性能指标均为示例。文件操作不会读取、上传、下载、覆盖或删除真实文件；共享目录是固定的演示目录，不提供真实目录选择器。文字通过隐藏且可聚焦的 textarea 收集，输入事件只更新内存中的模拟远端记事本；不会发送到真实设备。快捷键除退格、换行与 Tab 外仅显示模拟按键反馈，不实现记事本光标移动或系统剪贴板。触控、画质、真实媒体、手势、原生输入法、系统文件选择器和鸿蒙 API 仍需单独实现与真机验证。原型不持久化设备或密码，不在网址与活动记录中保存密码。

临时邀请 10 分钟、现场批准 60 秒是设计参数，通过模拟事件展示到期；固定协助码不是安全凭据生成。无人值守 15 分钟无输入断开、最长 8 小时沿用主规格要求，原型不运行这些真实计时器。每次重连都需重新满足当前访问策略，不能沿用旧会话权限。

完整流程与验收目标见 [DESIGN.md](DESIGN.md)。无人值守和文件传输属于扩展设计，未改变主规格的 M1／M2 门槛或现有 POC 的交付范围。

## 隐藏输入框设计

隐藏输入控件放在会话画面之外，避免界面重绘打断输入法。它可聚焦而非 `type=hidden` 或 `display:none`；手机尝试在用户点击键盘的同一事件中调用系统输入法，桌面接收已聚焦的物理键盘输入。

组合输入期间不提交拼音草稿；组合结束与随后输入事件使用同一差量基线，避免重复提交。普通空格、换行和退格保留原义。不在每次输入时重建整个页面。离开焦点、切到仅查看、撤权、断开、切角色或打开其他面板会停止捕获、丢弃未确认组合，并清空隐藏缓存；下次连接不保留上一会话文字。

系统保留快捷键、原生软键盘弹出/避让及实际跨端输入仍需真机验证。这个原型的接收端始终是只读模拟记事本，不是本机 OS 输入注入。

## 验证说明

- `node --check`：控制端、被控端、会话、文件模块及静态服务通过语法检查。
- 浏览器验证：错误密码就地提示、正确密码直接进入桌面、仅查看／控制切换、浮动栏收起展开、键盘入口，以及手机横竖屏、平板和 PC 布局。远端桌面保持 16:9，工具随本机尺寸适配。
- 浏览器验证：仅查看时申请上传不会自行授权；被控端分别允许上传下载；同名文件保留两份；手动推进到完成；手机文件页签无横向溢出。
- 浏览器验证：控制端偏好设置可回写默认访问方式、默认模式、连接策略、画面显示和画质；临时协助／无人值守一次性选择与默认值分离。被控端可登记／撤销示例可信设备，撤销后显示“无人值守待登记”并拒绝密码连接。
- 独立内存复核：临时协助审批、操作授予与当前模式分离、文件按方向撤权、断开停止失败与进行中任务、新设备不继承旧队列，报告的问题均已复测修正。

上述浏览器条目属于 v2 验证记录。v3 的六个 JavaScript 文件通过语法检查；组合输入去重、空格、换行、退格与中途停止完成事件检查，修复不可取消事件重复提交后，13 项定向复测与接线检查通过。输入提交只更新记事本文字，不重建会话区域。

本轮浏览器工具被安全策略拦截，未完成浏览器实测或系统软键盘验证。没有执行实际网络、媒体、文件传输、ArkUI、构建或真机验证。

## 隔离边界

本轮只修改本目录内原型。未修改 Rust／Flutter／ArkUI、构建签名、MCP 配置、主规格或共享进度文档；不运行 POC 构建、安装、设备连接或验证命令。生产及 POC 运行路径的回归面为空；原型自身的连接入口、会话布局和授权事件是本轮验证范围。

`index.html` 为入口，`app.js` / `styles.css` 管理设备页、连接与预览工具，`session.js` / `session.css` 展示远程桌面会话，`keyboard.js` 管理隐藏输入控件与组合输入事件，`files.js` / `files.css` 展示模拟文件传输，`host.js` / `host.css` 展示被控端，`server.cjs` 提供独立静态服务。所有文件均属于可丢弃的设计原型。
