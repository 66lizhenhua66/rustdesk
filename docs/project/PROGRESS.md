最新更新（2026-10-03，原生正式界面）：按当前原型推荐 A 方案新增默认 `Desk` 工作台与 `RemoteSession`，原 `Index` 作为连接诊断保留。设备 CRUD、导入预览、搜索、常用及真实获批连接记录已接入原有资料；连接、批准等待、原生 Surface、浮动工具和断开状态接入既有正式只读视频。手机底栏/单列、中宽导航轨/双列和宽屏侧栏已实现；原型、用户签名及工具配置保留。视频仍默认关闭，须 Windows 本机显式启用及 CM 逐连接批准，不开放系统输入、无人值守、文件或 ID/中继连接。

本轮 77 项原有回归加 5 项界面模型测试共 **82 项通过**，鸿蒙双 ABI/HAP 构建通过；API22 手机模拟器的设备 CRUD、冷启动读取、横竖屏切换、批准等待与超时，以及 API24 2in1 模拟器的中宽/宽屏布局已验证。手机合成 VP8 视频的浮动工具栏、工具面板、收起/展开、会话旋转、返回设备保持同一 Surface 和断开清屏已通过；合成视频不是正式 Windows 桌面，2in1 窗口宽度验证不是平板真机验收。Windows Debug 首次因 EXE 占用失败，在确认无活动连接、核验并停止本仓库测试进程后重试通过，随后恢复原回环视频服务与 CM。

本轮用户已实际点击 Windows CM 普通蓝色“接受”，新 Desk 页面成功显示真实 Windows 主屏 1152×720。初次观察接收/呈现 335/336 帧、1650 KiB，最终 1327/1328 帧、6671 KiB；两类计数独立限频更新，不要求同次读取相等。真实会话的横竖屏、返回工作台保留同一 Surface 和目标、返回会话、断开后 Surface 为 0、重连重新等待批准、取消新等待请求后 Surface 为 0 均通过。收尾时控制端回到设备页，正式服务只监听 `127.0.0.1:21120`，没有活动连接，未自动批准。详见 [本轮验证记录](research/2026-10-03-native-controller-ui-validation.md) 与 [原生界面计划](plans/2026-10-03-native-controller-ui.md)。真实系统键鼠仍未开放，真机继续后移且未验收，不阻塞后续开发。下面保留前阶段快照与历史证据，以最新记录为准。
