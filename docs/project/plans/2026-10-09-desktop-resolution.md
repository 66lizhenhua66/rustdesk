# 桌面分辨率策略与切换恢复

日期：2026-10-09。基线：`ce1b8682e`。用户确认同时支持保持远端桌面和同步调整桌面的建议，授权补齐切换、采集重建、回退和恢复。

## 已确定行为

- 默认保持 Windows 桌面，分辨率、压缩清晰度、FPS 独立选择。分辨率可跟随源画面或选择720p/1080p/1440p传输上限；跟随源画面最多4096单轴、8294400像素，4K性能另行实测。
- 同步模式只允许普通获批且输入控制已启用的会话显式申请。列出主屏驱动支持尺寸，不强制修改DPI、刷新率、方向，不写持久显示设置。应用设置时提示本机可能闪屏或窗口重排。
- 连接时始终使用保持策略，不能把上次同步选择自动应用到 Windows；切回保持策略先恢复本次连接前的显示模式。
- 切换使用单请求确认流程。释放按键、清旧输入、停旧采集并等待退出；模式变更后创建新采集/编码器，首关键帧准备好才确认并交付新帧。输入令牌与屏幕几何同步刷新。
- 可恢复失败返回上一实际设置及明确原因，视频继续；恢复失败则关闭会话并保留恢复记录。原始模式以本次连接开始时为准。
- 正常断开/退出尽力恢复原模式；异常退出的记录在下次服务启动检查恢复。检测到本机后续手工改动或显示拓扑变化时不覆盖它。恢复不是崩溃瞬间执行，不引入独立监控服务。
